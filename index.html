What Is CodeWhale?

CodeWhale is a terminal-native coding agent built around DeepSeek V4. It goes beyond simple Q&A — it finishes tasks. The key innovation is a "Constitution" — a formal hierarchy of 9 authority tiers that keeps the model oriented instead of drifting. It supports tool execution, workspace editing, sub-agents, MCP protocol, and automatic model routing.

Key Features

Constitution-based agent framework with 9-tier authority hierarchy
Auto mode - chooses model (Flash/Pro) and reasoning level per turn
Sub-agents - up to 20 concurrent background tasks
LSP diagnostics after every edit (rust-analyzer, pyright, TS, gopls, clangd)
Plan/Agent/YOLO three-tier approval gate
MCP protocol, HTTP/SSE runtime API, ACP adapter
Side-git snapshots - /restore and revert_turn rollback
macOS Seatbelt sandbox, Linux Landlock detection
Live cost tracking with cache hit/miss breakdowns

Install

# npm (easiest)
npm install -g codewhale

# Cargo (Rust 1.88+)
cargo install codewhale-cli --locked
cargo install codewhale-tui --locked

# Docker
docker run --rm -it -e DEEPSEEK_API_KEY="sk-..." ghcr.io/hmbown/codewhale:latest

# China mirror
npm install -g codewhale --registry=https://registry.npmmirror.com
