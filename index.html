核心功能

支持 20+ 域名服务商：阿里云、腾讯云、Cloudflare、华为云、GoDaddy 等
支持 IPv4/IPv6 双栈，自动检测公网地址
网页配置面板，默认禁止公网访问
默认5分钟同步一次，支持自定义间隔
支持同时配置多个 DNS 服务商和多个域名
Webhook 通知：Server酱、Bark、钉钉、飞书、Telegram
支持 TTL 和自定义参数（地域解析等）
支持 Docker 部署，一键启动

快速开始

# Docker 启动
docker run -d --name ddns-go --restart=always --net=host -v /opt/ddns-go:/root jeessy/ddns-go

# 浏览器配置
http://localhost:9876

# Windows (管理员)
.\ddns-go.exe -s install

# Linux/Mac
sudo ./ddns-go -s install
